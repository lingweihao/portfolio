# 个人作品集网站（LIN WEI · Portfolio）

一个杂志式排版的个人作品集网站，展示前端开发与视觉设计方向的项目经历、技能与联系方式，支持桌面端与移动端浏览。

## 技术栈

- **HTML5** — 页面语义化结构
- **CSS3** — CSS 变量主题系统、Grid / Flex 布局、响应式设计、过渡动画
- **原生 JavaScript** — 无框架、无第三方库，数据渲染与交互逻辑均为手写

## 目录结构

```
portfolio/
├── index.html        # 页面入口
├── css/
│   └── style.css     # 全部样式（含深 / 浅两套主题变量）
└── js/
    ├── projects.js   # 项目数据（新增项目只需往数组追加对象）
    ├── main.js       # 列表渲染、导航、菜单、滚动动画、图片放大
    └── theme.js      # 深浅色主题切换与 localStorage 记忆
```

## 主要功能

- **项目作品展示** — 依据 `js/projects.js` 数据自动渲染，图文左右交替的杂志式条目
- **深浅色主题切换** — 导航栏右侧按钮一键切换，选择保存在 localStorage，刷新后保持；首次访问跟随系统偏好
- **响应式布局** — 桌面端横向导航，移动端汉堡菜单 + 全屏抽屉，项目条目自动退化为单列
- **滚动交互** — 当前区域导航高亮、区块一次性淡入动画、导航栏滚动后毛玻璃底色
- **图片放大（Lightbox）** — 点击项目配图全屏查看，Esc 或点击关闭
- **锚点平滑滚动** — 首页 / 作品 / 关于 / 联系四个区块间平滑跳转

## 运行方式

直接双击打开 `index.html` 即可浏览；或使用本地服务器：

```bash
cd portfolio
python -m http.server 8080
# 浏览器访问 http://127.0.0.1:8080
```

## 如何新增项目

编辑 `js/projects.js`，向 `PROJECTS` 数组追加一条对象（含 `no`、`cat`、`title`、`desc`、`tech`、`date`、`img`、`block` 字段），排版节奏与配色由 CSS 自动处理，无需修改样式。
